- 전체 테스트 81개, 실패·무시 0개. 단위 50개, HTTP/MCP 10개, 여러 후보 통합 3개, 경로 비교 9개, 저장·알림 6개, 보행 통합 3개.

- 보정 프로필 저장 후 기존 도보 10분→8분, 전체 이동 35분→33분, 출발 시각 2분 조정을 확인. 탑승 구간 25분은 유지.
- 1,000m / 12분 = 5km/h. 이후 같은 속도의 500m 도보는 6분. 같은 관측 ID 재전송은 표본 개수를 늘리지 않음.

- 지하철·버스·혼합·도보를 함께 비교하고, 작은 이득에는 현재 경로 유지, 충분한 이득에는 버스로 변경하는 회귀 테스트 통과.

실제 공개 MCP에서 `record_walking_observation` 미리보기와 `compare_travel_options`를 호출해 같은 결과를 확인했습니다. 미리보기는 `saved=false`, 개인 프로필 및 기록 개수는 `null`이었습니다. 실제 사용자 보행 기록은 테스트로 저장하지 않았습니다.
